## 🎨 카드 A — 브랜드형 (표지)

> **목적**: 브랜드 이미지로 시선을 끌고, 메인 메시지와 혜택을 전달
> **사용 위치**: 표지 (Cover)
> **변형**: 연출컷 / 누끼컷 (이미지 타입에 따라 레이아웃 분기)

### 레이아웃 — 공통

```
┌─────────────────────────────┐  ← top: 0
│   서브텍스트 (100px ↓)       │
│   메인텍스트 1줄            │
│   메인텍스트 2줄 (선택)     │
│                             │
│         이미지 영역          │
│                             │
│   ┌───혜택 박스───┐          │  ← bottom: 108px
│   │ 라벨 │ 값 │  │          │
│   └────────────┘          │
│ ━━━━━ 버튼 영역 ━━━━━━━━     │  ← height: 108px
└─────────────────────────────┘
```

#### 텍스트 영역 (헤드라인 + 서브)
- 위치: 상단 절대배치 `top: 0`
- 패딩: `padding: 100px 60px 0`
- 정렬: 가운데 정렬 (`text-align: center`)
- z-index: 3

#### 이미지 영역
- **연출컷**: `width: 750px`, `height: 1000px` (카드 전체) + 상단 520px 그라디언트 오버레이
- **누끼컷**: 텍스트 아래부터 혜택 박스 위까지 동적 계산 영역
  - `top = 100 + 48 + (헤드라인2 있으면 154 / 없으면 77) + 40`
  - `height = (1000 - 108 - 166) - 40 - top`
- z-index: 1
- `object-fit`: 연출컷 `cover` / 누끼컷 `contain`
- 변환: `transform: translate(X, Y) scale(S)` (위치 조정 적용)

#### 혜택 박스 영역
- 위치: `bottom: 108px`, 좌우 패딩 30px
- 배경: 흰색 라운드 박스 (`border-radius: 20px`)
- 내부 패딩: `36px 40px`
- 표시 조건: 혜택 개수 ≠ '없음' 일 때만

#### 버튼 영역
- 위치: 하단 `bottom: 0`
- 크기: `width: 750px × height: 108px`
- 배경: 사용자 지정 (`btnColor`, 기본값 `#2f8de2`)
- 정렬: 가운데 (텍스트 + 화살표 SVG)
- z-index: 3

- ※3 **혜택 값 색상**: 버튼 밝기 `≥ 200` → `#111` / `< 200` → 버튼 컬러
- ※4 **버튼 텍스트 색상**: 버튼 밝기 `≥ 168` → `#000000` / `< 168` → `white`
- 밝기 계산식: `(R×299 + G×587 + B×114) / 1000`

#### 자동 컬러 추출 상세
- **누끼컷**:
  - 배경 컬러: 이미지 중앙 영역(40~60%)에서 평균 색상 추출 → `_autoBgColor`
  - 버튼 컬러: 추출 색상에 채도 +0.25, 명도 -0.25 적용 (`calcBtnColor()`)
- **연출컷**:
  - 그라디언트 컬러: 16×16 다운샘플 → 가장 많이 등장한 색상 (밝기 20~230 범위)
  - 버튼 컬러: 동일 베이스 색상에 `calcBtnColor()` 적용

| 항목 | 연출컷 | 누끼컷 |

## 🎨 카드 B — 가격강조형 (표지)

> **목적**: 제품 이미지와 가격을 강조하여 구매 욕구 자극
> **사용 위치**: 표지 (Cover)
> **변형**: 상품 1개 / 상품 2개 (다른 레이아웃)

### 레이아웃 — 상품 1개일 때

```
┌─────────────────────────────┐
│       헤드라인 (80px ↓)      │  ← top: 0, padding-top: 80px
│                             │
│  ┌─── 흰색 라운드 박스 ───┐  │  ← top: 190px, left/right: 40px
│  │  날짜 │ 시간 (선택)     │  │  ← top: 24px (in box)
│  │ ┌──── 이미지 박스 ────┐ │  │
│  │ │                      │ │  │  ← 회색 배경, 라운드
│  │ │       이미지         │ │  │
│  │ │                      │ │  │
│  │ └──────────────────────┘ │  │
│  │  브랜드명                │  │
│  │  제품명                  │  │
│  │  -할인%  판매가  원가    │  │
│  └──────────────────────────┘  │  ← bottom: 162px
│ ━━━━━━ 버튼 영역 ━━━━━━━━━     │  ← bottom: 40px, height: 100px
└─────────────────────────────┘
```

#### 헤드라인 영역
- 위치: `top: 0`, `padding: 80px 60px 0`
- 너비: 750px
- 정렬: 가운데 (`text-align: center`)
- z-index: 2

#### 상품 박스 (흰색 라운드 박스)
- 위치: `top: 190px`, `left: 40px`, `right: 40px`, `bottom: 162px`
- 배경: 흰색
- 모서리: `border-radius: 20px`
- overflow: hidden
- z-index: 1

#### 날짜/시간 영역 (선택)
- 위치 (박스 내부): `top: 24px`, `left/right: 24px`
- 표시: `showDate: 'on'`일 때만
- 정렬: `justify-content: space-between` (좌: 날짜, 우: 시간)
- z-index: 2

#### 이미지 영역
- 위치 (박스 내부): `top: 70px` (날짜 있을 때) 또는 `20px` (없을 때)
- 좌우: `left/right: 20px`
- 하단: `bottom: 186px`
- 배경: `#f5f5f5`
- 모서리: `border-radius: 20px`
- overflow: hidden
- `object-fit: cover`
- 변환: `transform: translate(X, Y) scale(S)` (위치 조정 적용)

#### 가격 정보 영역

- 구성: 브랜드명 → 제품명 → (할인율 + 판매가 + 원가) 세로 배치
- gap: 12px

#### 버튼 영역

- 모서리: `border-radius: 20px`

| 이미지 위치 조정 | ✅ | 이미지 1, 2 각각 가능 |
| 자동 컬러 추출 | ❌ | `_btnColorAuto: false` (기본 비활성) |
| 화살표 토글 | ✅ | `btnArrow` (on/off) |
| 날짜 표시 토글 | ✅ | `showDate` (on/off) |
| 상품 개수 조정 | ✅ | 1개 / 2개 (레이아웃 변경) |
| 텍스트 자동 색상 분기 | ❌ | 모든 색상 고정 |

#### 입력 검증
- **할인율**: 숫자만 입력 (정규식 `[^0-9]` 제거), 최대 2자리 + `%` 자동 부착
- **판매가/원가**: 숫자와 콤마만 입력 (정규식 `[^0-9,]` 제거), 최대 10자 + `원` 자동 부착
- **원가 빈값**: 입력 없으면 `원` 부착 안 함 (표시 자체 안 됨)

---

### 변형: 상품 1개 vs 2개

| 항목 | 상품 1개 | 상품 2개 |
|------|----------|----------|
| 상품 박스 위치 | `top: 190px ~ bottom: 162px` | `top: 200px ~ bottom: 160px` |
| 카드 개수 | 1개 (큰 박스) | 2개 (세로 배치, flex:1 균등) |
| 이미지 영역 | 박스 전체 너비 | `width: 240px` (좌측) |
| 가격 정보 위치 | 이미지 아래 (세로) | 이미지 우측 (가로) |
| 할인율 표시 | 인라인 (판매가 옆) | 별도 배지 (이미지 위) |
| 할인율 색상 | `#ef3c2c` 텍스트 | `#ef3c2c` 배경 + 흰색 텍스트 |
| 브랜드명 maxlength | 15 | 12 |
| 제품명 maxlength | 20 | 12 |
| 날짜/시간 위치 | 박스 상단 (공통) | 각 카드 상단 (개별) |
| 날짜 데이터 | `date`, `time` | `product1Date/Time`, `product2Date/Time` |

## 🎨 카드 C — 혜택형 (내지)

> **목적**: 다양한 혜택을 배지로 시각화하여 강조  
> **사용 위치**: 내지 (Inner)

### ⏳ 상세 명세 (작성 예정)

#### 레이아웃
- 상단 띠배너 영역:
- 이미지 영역:
- 배지 영역:
- 하단 유의사항 영역:

#### 타이포그래피
- 띠배너 텍스트:
- 배지 라벨 (할인 등):
- 배지 수치 (57%, 15% 등):
- 유의사항 텍스트: 26px / 두께 300 (Light) / 색상 rgba(255,255,255,0.7)

#### 색상
- 배지 기본 배경: `#2F2F2F` (이미지 어두울 때 `#3F3F3F`)
- 결제사 배지: 결제사별 브랜드 컬러 (`_payC` 객체)
- 무료배송 배지: `#2F2F2F`
- 사용자기재 배지: `#2F2F2F`
- 띠배너 컬러: 사용자 지정 (`bannerColor`)

#### 배지 종류
- **무결제계열**: 즉시할인, 상품쿠폰, 장바구니, 무료배송, 사용자기재
- **결제사계열**: 카카오페이, 네이버페이, 토스페이, 오늘의집페이

#### 배지 규칙
- 1개일 때: 모든 배지 가능
- 2개일 때: 1번은 무결제계열, 2번은 자유
- 3개일 때: 1~2번은 무결제계열, 3번은 결제사계열

#### 배지 간격
- 세로 배지 간 gap: 10px
- 배지 위치: 우측 상단 (top 30px 또는 134px when 띠배너 있음)
- 배지 크기: 160 × 160 px (원형)

#### 띠배너 종류
- 브랜드형: 사용자 컬러 + 텍스트
- 오마트: 고정 컬러 #ff8442
- 오세일: 사용자 컬러
- 오늘의딜: 고정 컬러 #FF4747
- 스오딜: 5탭 표시
- 없음: 띠배너 미표시

#### 인터랙션
- 이미지 위치 조정: ✅ 가능
- 자동 컬러 추출: ❌ 비활성
- 배지 밝게 토글: ✅ `darkImg` (이미지 어두울 때 배지 살짝 밝게)
- 유의사항 표시 토글: ✅ `showNotice`
- 유의사항 텍스트 편집: ✅ `noticeText` (30자 제한)
